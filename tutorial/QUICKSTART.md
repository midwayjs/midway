# 快速开始

## 前置要求

- Node.js 18+ 
- pnpm 8+

## 安装依赖

在 `tutorial` 目录下运行：

```bash
cd tutorial
pnpm install
```

## 启动教程

```bash
pnpm dev
```

浏览器会自动打开 http://localhost:4321

## 教程使用说明

### 如何学习

1. **阅读教程内容** - 左侧或中间区域显示教程文本
2. **查看代码** - 右侧编辑器显示示例代码
3. **运行代码** - 点击"运行"按钮查看效果
4. **修改尝试** - 修改代码，实时查看结果
5. **下一课** - 完成后点击"下一步"继续

### 快捷键

- `Ctrl/Cmd + S` - 保存代码
- `Ctrl/Cmd + Enter` - 运行代码
- `Ctrl/Cmd + Z` - 撤销修改
- `→` - 下一课
- `←` - 上一课

## 常见问题

### Q: 代码修改后没有生效？
A: 确保点击了"运行"按钮，或者刷新页面。

### Q: 编辑器中的代码可以下载吗？
A: 可以，所有示例代码都在 `src/templates/default/` 目录下。

### Q: 如何重置代码？
A: 点击编辑器右上角的"重置"按钮。

### Q: 遇到错误怎么办？
A: 查看浏览器控制台的错误信息，或参考教程中的说明。

### Q: 教程可以离线使用吗？
A: 可以，先构建：`pnpm build`，然后运行：`pnpm preview`

## 构建生产版本

```bash
pnpm build
```

构建产物在 `dist/` 目录下。

## 预览构建结果

```bash
pnpm preview
```
