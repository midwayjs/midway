# TutorialKit 预览功能说明

## ✅ 预览功能已配置

在第二课及以后的课程配置中，都添加了预览面板：

```yaml
previews:
  - port: 7001
    title: Midway 应用
```

## 🎯 学生可以做什么

### 1. 在预览窗口中访问应用

教程界面会显示三个主要区域：

```
┌──────────────────────────────────────────────────┐
│  教程内容          │  代码编辑器               │
│  (左侧)           │  (中间)                   │
├──────────────────┼──────────────────────────────┤
│  文件树           │  预览窗口/终端            │
│  (左下)           │  (右侧)                   │
└──────────────────┴──────────────────────────────┘
```

### 2. 预览窗口功能

**学生可以：**
- ✅ 直接在预览窗口中访问应用（自动加载 `http://localhost:7001`）
- ✅ 在 URL 栏输入不同的路径测试 API
- ✅ 看到实时的响应结果
- ✅ 刷新预览窗口
- ✅ 在新标签页打开（如果需要）

**示例：测试第五课的 API**

```yaml
# 第五课配置
previews:
  - port: 7001
    title: Midway 应用
```

学生可以在预览窗口的地址栏输入：

1. `http://localhost:7001/api/users`
   - 查看所有用户列表

2. `http://localhost:7001/api/users/1`
   - 查看 ID 为 1 的用户

3. `http://localhost:7001/api/users/search?keyword=张`
   - 搜索包含"张"的用户

### 3. 自动重载功能

```yaml
autoReload: true
```

- 修改代码后，应用自动重启
- 预览窗口自动刷新
- 立即看到修改效果

## 🎮 实际操作流程

### 学生视角

1. **打开第五课**
   - 左侧看到教程说明
   - 中间看到代码编辑器（`user.controller.ts`）
   - 右上看到终端输出（应用启动日志）
   - 右下看到预览窗口（Midway 应用）

2. **阅读代码**
   - 看到 `@Get('/api/users')` 定义了路由
   - 理解 `@Inject()` 注入了 `UserService`

3. **测试 API**
   - 在预览窗口地址栏输入：`/api/users`
   - 看到返回的用户列表 JSON
   - 验证代码运行结果

4. **修改代码**
   - 在编辑器中修改返回格式
   - 保存后自动重启
   - 刷新预览窗口查看新结果

## 🔧 技术细节

### 预览 URL 生成

TutorialKit 会：
1. 启动 WebContainer
2. 运行 `npm run dev`
3. Midway 应用监听 7001 端口
4. TutorialKit 创建预览 URL：`http://localhost:7001`
5. 在 iframe 中显示预览内容

### 多端口支持

如果需要多个预览（例如前后端分离）：

```yaml
previews:
  - port: 7001
    title: 后端 API
  - port: 3000
    title: 前端应用
```
