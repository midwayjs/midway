# Midway.js 交互式教程 - 课程索引

## 📚 课程目录

### 第一部分：创建应用

**目标**：了解 Midway 项目结构，创建第一个 API 接口

| 课程 | 标题 | 主要内容 | 时长 |
|------|------|----------|------|
| 1.1 | 项目结构介绍 | 目录结构、核心文件说明、开发习惯 | 5分钟 |
| 1.2 | 创建第一个 Controller | 装饰器、路由、HTTP 方法 | 10分钟 |
| 1.3 | 获取请求参数 | @Query、@Param、@Body、@Headers | 15分钟 |

**学习成果**：
- ✅ 理解 Midway 项目结构
- ✅ 能够创建基本的 Controller
- ✅ 掌握各种参数获取方式

|------|------|----------|------|
| 2.1 | 创建第一个 Service | @Provide、Service 职责、异步方法 | 10分钟 |
| 2.2 | 依赖注入的使用 | @Inject、IoC 容器、作用域 | 15分钟 |

**学习成果**：
- ✅ 理解依赖注入的概念和优势
- ✅ 能够创建和使用 Service
- ✅ 掌握 Controller 和 Service 的协作

## 🎯 学习路径建议

### 初学者路径（按顺序学习）
1. 完成第一部分 - 建立基础认知
2. 完成第二部分 - 理解核心概念
3. 完成第三部分 - 掌握实战技能
4. 完成第四部分 - 学习进阶特性
5. 完成第五部分 - 了解最佳实践

**预计总时长**：2-3 小时

### 有基础学习者路径
- 快速浏览第一、二部分
- 重点学习第三、四、五部分
- 关注最佳实践章节

**预计总时长**：1-1.5 小时

## 📖 学习建议

1. **边学边练**：每个示例都亲自运行一遍
2. **修改尝试**：尝试修改代码，观察结果
3. **记笔记**：记录重要概念和容易忘记的点
4. **做项目**：学完后立即开始一个小项目实践
5. **查文档**：遇到问题及时查阅官方文档
