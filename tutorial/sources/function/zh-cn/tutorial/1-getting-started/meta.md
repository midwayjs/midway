# 开始使用 Midway.js

欢迎来到 Midway.js 交互式教程！

在本教程中,您将学习如何使用 Midway.js 构建一个现代的 Node.js Web 应用。

## 您将学到什么

- ✅ 创建第一个 Midway 应用
- ✅ 理解项目结构
- ✅ 创建 Controller 处理 HTTP 请求
- ✅ 使用 Service 组织业务逻辑
- ✅ 掌握依赖注入模式
- ✅ 处理请求参数和返回响应

## 技术栈

本教程使用纯 Node.js 项目方案，以 `@midwayjs/koa` 作为 Web 框架：

- **TypeScript** - 类型安全的 JavaScript 超集
- **Koa** - 轻量级 Web 框架
- **依赖注入** - 现代化的架构模式
- **装饰器** - 优雅的元数据声明方式

让我们开始吧！
