# Service and Dependency Injection

In this part, you'll learn one of Midway's core features: dependency injection.

## Why Service?

Putting all logic in controllers makes code hard to test and maintain.

A service layer helps you:

- Separate business logic
- Reuse code
- Improve testability
- Keep responsibilities clear
