# Getting Started with Midway.js

Welcome to the Midway.js interactive tutorial.

In this part, you will learn how to build a modern Node.js web application with Midway.js.

## What you'll learn

- Create your first Midway app
- Understand the project structure
- Build controllers to handle HTTP requests
- Use services to organize business logic
- Understand dependency injection
- Handle request parameters and responses

## Tech stack

This tutorial uses a plain Node.js setup with `@midwayjs/koa` as the web framework:

- **TypeScript**
- **Koa**
- **Dependency Injection**
- **Decorators**

Let's begin.
